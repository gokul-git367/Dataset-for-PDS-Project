# Dataset-for-PDS-Project-from-kaggle

This repository contains stock price datasets for:

- Apple (`apple/AAPL.csv`) - https://www.kaggle.com/datasets/meetnagadia/apple-stock-price-from-19802021
- Coca-Cola (`cocacola/COCO COLA.csv`) - https://www.kaggle.com/datasets/meetnagadia/coco-cola-stock-data-19622021
- Netflix (`netflix/NFLX.csv`) - https://www.kaggle.com/datasets/meetnagadia/netflix-stock-price-data-set-20022022
